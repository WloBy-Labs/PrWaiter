# PrWaiter 0.6.0

第一个可下载的版本。

并行的 PR 太多、互相还有先后关系时，「现在该催哪一个」这件事其实很难在 GitHub 上看出来。
PrWaiter 把手头的 PR 按功能 / bug 归类、按先后关系组织成树，实时显示各自的
review 与 CI 状态，直接告诉你哪个已经万事俱备。

## 装什么、怎么装

DMG 打开后把 PrWaiter 拖进 Applications 即可。

**还需要 [GitHub CLI](https://cli.github.com/)** —— PR 的实时状态靠它拉取。
不用自己先装：首次打开如果没检测到，右上角齿轮会变橙色，进设置页可以一键用 Homebrew 装，
装完点「在终端登录」完成授权。

> Release 包用固定的自签身份签名（`PrWaiter Signing`）。证书没经过 Apple 公证，
> 所以**首次打开 Gatekeeper 会警告**：在「系统设置 → 隐私与安全性」里点一次
> 「仍要打开」，或者右键点 App 选「打开」。

## 主要功能

- **多项目**：顶部标签一个仓库一个，切换只看该项目的 PR
- **描述块**：写功能 / bug 的说明，把相关 PR 收在下面
- **树形先后关系**：PR 挂在另一个 PR 下面表示「要等它先合并」，缩进连线一眼看清层级
- **拖拽组织**：拖到块上归类、拖到块之间调顺序；项目标签也能拖着排序
- **十档状态**：可合并 / CI 失败 / 需修改 / CI 运行中 / 等 review / 等依赖 / 草稿 /
  已合并 / 已关闭。描述块右侧按状态分项计数，分类互斥所以加起来正好是 PR 总数
- **折叠**：块左侧一条整高的折叠区，收起来也不影响统计
- **编辑 / 冻结两态**：默认冻结只读，避免误拖误删

## 设计上的两个取舍

**本地只存 GitHub 不知道的事** —— 项目划分、描述块、PR 的树形归属和备注。
标题、review、CI、是否合并每次实时拉取，不存副本，所以状态永远不会过期，
也没有任何同步逻辑需要维护。

**「CI 失败」「需修改」排在「等依赖」前面** —— 你的 CI 红了就是红了，
上游合没合并不影响这件事该你去修。
