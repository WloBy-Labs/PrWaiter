# PrWaiter 0.9.0

**设置里可以检查更新并一键升级了。**

## 怎么用

设置 → 更新：显示当前版本和检查结果。有新版本时点「下载并安装」，App 会下载 DMG、
校验签名、替换自己、然后重启。

启动时会自动检查（可关）。「查到新版本就自动安装」默认**关** —— 替换正在运行的 App
会让它重启，这种事不该在你不知情时发生；想全自动自己打开。

## 实现上的几个决定

**走 `gh` 而不是直接发 HTTP 请求。** GitHub 对未认证请求限 60 次/小时且按 IP 计，
公司出口 IP 后面很容易撞上 403；`gh` 带认证，限额高得多。顺带也不用在 App 里再引
一套网络栈。

**版本号按数字逐段比较。** 字符串比较会翻车 —— `"0.10.0" < "0.9.0"` 是字符串序，
会把新版本判成旧的。

**安装前校验下载包的签名**，坏包直接中止。装上一个签名坏掉的 App 等于装了个打不开
的东西，比不更新更糟。

**替换正在运行的自己**没法在进程内完成，交给一个脱离出去的脚本：它等本进程退出后
再替换并重新打开。
