## 智能整理 PR

- 支持配置多个 OpenAI 兼容服务，拉取模型、选择思考等级和测试连接。
- 新增 PR 后自动生成待确认建议；也可手动分批分析当前项目的全部 PR。
- AI 只选择已有分组，位置和备注分别预览、勾选、批量选择并手动应用。移动时保留 PR 依赖，建议备注追加而不覆盖原备注。
- 自动分析会向选定服务发送仓库 PR 内容和分组信息，可在设置中选择或关闭。

## 看板与性能

- 新增进行中、全部、已完成及状态筛选；点击标题查看 PR 详情。
- 优化看板统计和滚动，完整 PR 查询按批次拉取，减少大型查询超时。

## 安装说明

下载 DMG，将 PrWaiter 拖入 Applications；已有安装可在设置中检查更新。AI 的 API Key 以明文保存在本机配置文件中，仅当前用户可读写。
