# PrWaiter 1.0.0

**一个新用户拿到 App 之后，不用问人也能把它用起来。** 这是 1.0.0 的门槛，到这一版为止够到了。

从 0.1.0 到这里，一直在补「能不能自己讲清楚自己」这一段：状态怎么分、缩进是什么意思、
拖到哪儿是什么效果。这一版把最后一块补上了 —— 首次打开会自己带你走一遍。

## 首次打开的聚光灯导览

四周压暗，把当前要讲的控件挖个洞露出来、描一圈边，旁边浮一个气泡说明它的作用，
「下一步 / 上一步 / 跳过」逐步走完 8 步：

项目标签 → 描述块 → 状态颜色 → 折叠区 → 编辑开关 → 拖动手柄 → 刷新 → 设置

想重看，在设置的「关于」里点「重新查看」。

**每一步都指着一个真实控件，没有纯说明页。** 挖不出洞的那一步看着就只是个居中的对话框，
那不叫导览 —— 测试里把这条钉住了。

**导览期间铺的是一份样板数据**（编号 900+），不是你的 PR。首次打开时你一条数据都没有，
指着空看板讲「描述块」「状态颜色」等于指着空气。样板还刻意覆盖了
「可以合了 / 等上游 / CI 挂了」三种状态，颜色那一步才讲得清。

## 这一版还修了

**多重 backport 挂错了父节点。** backport 的 backport，标题会一路带上来源
（`…… (backport #77408) (backport #77463)`）。原来取第一个引用，于是挂到了最上游那个，
跳过中间一环；现在取**最后**一个 —— 那才是直接的上一手，先后关系才是连着的。
已经摆错的会在下次刷新时搬到正确位置，一次性的，不会跟你后来的手工调整较劲。

**子层的块拖不动顺序。** 投放缝原来只在根级之间有，同一个父块下想调两个 PR 的先后
只能删了重加。现在每一行前面都有缝，缝跟着所在层缩进，哪一层都能调同级顺序。

**每行显示 PR 的目标分支。** 一组 backport 的标题一字不差，唯一的区别就是打到哪个
分支上；不显出来，几行长得一模一样的 PR 看着就像重复了。

**新导入的 backport 按编号倒序插到父块下面**，不再一律追加到末尾 —— 免得刚开的
backport 沉到一堆已合并的下面。只给新来的挑位置，不重排你已经摆好的兄弟。

## 安装

DMG 拖进 Applications 即可。

> 包用固定的自签身份签名（`PrWaiter Signing`），没经过 Apple 公证，所以**首次打开
> Gatekeeper 会警告**：在「系统设置 → 隐私与安全性」里点一次「仍要打开」，
> 或者右键点 App 选「打开」。

运行还需要 [GitHub CLI](https://cli.github.com/)。没装也不会崩，进设置页可以一键装。

已经装了 0.9.0 的话，直接在设置 → 更新里点「检查更新」就能升上来。
