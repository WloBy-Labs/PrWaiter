# PrWaiter 0.7.1

自动导入的范围从「作者是我」扩大到「作者是我**或**指派给我」。

## 为什么

机器人自动创建的 backport PR，作者是机器人（比如 `app/mergify`），只是把你设成
指派人。0.7.0 只查 `author:@me`，这类 PR 一个都进不来 —— 而它们恰恰是最需要盯的：
你合了主干那个 PR，剩下要追的就是这一串 backport。

实测在 StarRocks 仓库里，只有 assignee 查得到、author 查不到的有 **23 个**，
全是 mergify 建的 backport。

## 实现

`gh pr list` 的 `--author` 和 `--assignee` 是 AND 关系，所以分两次查再取并集。
一条失败另一条仍然可用，两条都失败才算这轮导入失败。
